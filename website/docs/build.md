# 制作实验室

## 自由浏览

七个环节的左侧导航始终可选，无需先完成前一项。上一步、下一步用于自由浏览，仅在列表边界限制方向。浏览步骤不会将该项标成已完成，也不会清空已经输入的文件名、选项或检查记录。

模拟任务运行中切换环节，会取消当前任务并提示；取消的任务不会在其他环节中继续修改完成状态。贴片与固件环节的文件有效性检查、手工装配确认、烧录内部连接／写入／校验顺序和最终测试条件继续保留。修改既有配置时，仍会撤销受影响的当前及后续确认。

移除下方“制造设备 / 三维模型待接入”及对应 ModelSlot，不再展示 PCB、贴片机、打印机的待接入模型。
