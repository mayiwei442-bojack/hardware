# 交互试用

试用区左侧为二维键盘，右侧为电脑显示屏。所有行为均为本页示例，不连接设备、Codex、已安装应用或媒体播放器。界面明确显示该边界，不伪造设备连接、命令执行或语音识别结果。

## 与原项目的对应关系

| 展示 | 原项目来源 | 本页行为 |
| --- | --- | --- |
| 13 个 Codex 按键 | `device/app/README.md` 的 Codex 模板表 | 显示目标软件、实际组合键和用途；会话、请求与面板使用明确标注的示例内容 |
| 旋钮旋转与按压 | `device/fw/src/keymap.rs` 的音量增减与静音默认值 | 始终调整演示音量，按压切换静音，不随页面切换成其他参数 |
| 摇杆 | 同文件中的方向键默认值 | 发送方向键的效果示例，移动九宫格中的选中项 |
| 触摸板 | 同文件中的播放／暂停默认值；`device/app/README.md` 的单区触摸限制 | 轻触切换媒体示例的播放状态，不支持滑动切换应用 |
| 应用快捷键 | `device/app/src/behaviors.rs` 中 VS Code、Chrome、Blender 预设 | 显示软件名称、组合键、用途与本页反馈，不启动软件 |

## 触摸板场景

- **工作时听音乐**：工作期间临时需要回应他人，轻触暂停背景音乐，处理完后再次轻触继续。
- **跟着教程操作**：观看操作教程时，轻触暂停并保留当前步骤，完成跟做后再轻触继续。

两个场景使用同一个默认播放／暂停媒体键。由支持系统媒体键的当前播放器响应；场景选择只是帮助理解用途，不代表设备具备播放器识别或应用自动切换功能。本页不播放音视频。

播放状态、场景和音量在切换视图时保留。静音不改变播放状态；旋钮在任何视图中均只展示音量增减。复位恢复全部示例状态。

## 应用快捷键

每个示例显示明确的目标软件及组合键：

- VS Code：打开命令面板、切换集成终端。
- Google Chrome：新建标签页、定位地址栏。
- Blender：切换编辑模式、播放／暂停动画。

这些行为需要先在原项目配套软件中绑定设备按键，并使目标软件处于前台。平台按钮显示对应组合键；选择软件只切换示例，点击操作只更新本页按键反馈。

## 已删除的额外模拟

删除音色、音频延迟、音频电平、固定的“标准／快速／深入”模型、推理强度滑杆、旋钮调推理强度或字号、任意应用切换、触摸滑动、虚构代码文件与笔记编辑器、自定义整理代码命令、自动语音转写、伪造终端连接日志与“已连接”状态。移除不再使用的旧命令面板组件。

## 操作和布局

旋钮支持拖动、滚轮、加减按钮、方向键和独立按压按钮。摇杆支持拖动、方向按钮和方向键；释放后回中。试用区获得焦点后，实体键盘的 `1–9`、`0`、`Q`、`W`、`E` 对应 01–13；在搜索输入框中输入不会触发设备按键。

桌面为左右两栏，900 像素及以下改为键盘在上、显示屏在下。减少动态效果设置会停止唱片旋转与视图位移动画。

主要实现：`data/trial.ts`、`lib/input.ts`、`Workstation.tsx`、`InputPanel.tsx`、`ComputerScreen.tsx` 和 `workstation.css`。
