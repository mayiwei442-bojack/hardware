# 制作实验室交互工作台

七个制作环节可自由切换，保留原有黑 / 酸绿 / 紫色风格与下游失效规则。
进入 `http://localhost:3100/#build` 即可选择任意环节；运行中的任务会在切换时中止，完成状态不会凭浏览自动增加。

## PCB 制板

直接下载网站随附的 `keyboard-gerbers.zip`，不上传文件、不模拟打板订单。
四层、95 × 95 mm、FR-4、1.6 mm、1 oz 来自实际制造资料，在下载按钮下方显示。

## SMT 贴片

使用界面中的 PCB 样板参考参数，选择贴片数量，提供 BOM 和 CPL，确认物料，再检查双面贴装预览。
物料行和预览中的位号互相联动，可以调整元件方向；模拟 DFM 会检查数量与方向是否符合项目参考坐标。
方向不一致时需要复位，再次检查后才能提交。

物料与预览使用项目随附参考资料；用户上传的自定义文件仅作格式检查。
模拟 DFM 不是制造商 DFM，不判断焊盘、间距、库存或可制造性。
完整采购型号请使用原始 BOM；界面将电阻、电容合并为便于教学的分类。

## 手工装配

先选择机械轴并安装第一颗 SW03，随后可逐个安装或自动安装剩余机械轴。
编码器对应 SW1，摇杆对应 J1。界面把制造资料中的 SW3–SW9 补零显示为 SW03–SW09，以对应三维模型命名。
支持桌面拖放、点击和键盘操作。错误零件与孔位组合会给出提示。
翻到背面后长按焊点约 0.7 秒固定，键盘可长按空格；也可批量演示其余焊点。
返回正面点击已安装零件可拆下，同时清除该零件的固定状态及下游完成结果。
三维检查按需加载现有 GLB，仅展示 PCB、灯珠、触摸区域和当前已安装部件。

## 固件烧录

点击烧录器或拖线至 J2，选择 HEX，开始写入，再校验与启动。
数据方块沿线移动，64 个示意存储格随进度填充；校验显示扫描线，启动显示键盘预览。
写入中可随时断开连接；断开或切换环节后中止当前过程，从零重新写入，不能直接校验或启动。断开连接后还需重连。
内置 HEX 与项目发行版对应；真实烧录需要 USB-C 供电和 SWD，本站不访问真实设备。
芯片格子仅示意进度，不代表实际 Flash 页布局；校验是演示结果，不是读取芯片校验。

## 验证

`npm run typecheck`、`npm run build`、`npm run test:e2e`。
`tests/build-lab.spec.ts` 验证 Gerber 下载、错方向 DFM、拆装与长按焊接、烧录断线及切换环节后的重试和窄屏布局。
`tests/site.spec.ts` 中原有七步完整流程已适配新交互，继续检查最终输入测试及上游配置失效。
设置 `BUILD_LAB_SCREENSHOTS` 可将工作台的截图保存到指定目录。
