# 建模与验收计划

正式建模开始：2026-10-01 03:30 Asia/Shanghai。第二次执行：同日 08:40，恢复断点；若模型完成则独立重复验收。截止依据是实际 300 分钟额度用量，不是工作时长。

## 批次顺序（每批均：制作 → 保存 → 渲染 → view_image 实看 → 修正 → 再看 → 更新进度）

1. **尺寸/源 CAD 基准**：读取资料整理、source_inventory/source_meshes；导入原壳/旋钮/摇杆帽到独立参考场景，统一 mm/m 和坐标；生成顶、前、右、后、底正交参考，核对 USB 后侧方向。保留原始网格作为隐藏参考。搭建命名集合、相机和灯光；写源尺寸核对报告。
2. **壳体及 PCB 装配**：复用源壳形状，必要时局部可编辑清理；PCB 95×95×1.6、R6、四角孔、USB 开口/承托正确。建立原位矩阵和爆炸层级。渲染顶、后 USB 特写、侧面和底部，检查板壳穿插与紧固孔同轴。
3. **13 个开关与键帽**：模块化 Choc 轴体/芯/帽，独立 13 套命名。键帽 4 透明、8 白、1 黄，符号依实拍。阵列定位后独立交互，不合并成一块。渲染整机俯视、透明帽特写、按下极限状态；逐键检查轴帽连接与相邻间隙。
4. **EC11 与 RKJXV**：固定机械座、活动轴、帽分离。EC11 条纹帽、金属壳、焊脚；摇杆金属笼/黑底座/侧电位器可识别，轴双向转动的 pivot 正确。渲染中立、旋转/按压、四向倾斜；检查帽与座、邻键碰撞。
5. **简化内部电子件与灯光**：按 source_inventory 中 88 footprint 定位可识别器件；B 面 MCU/QFP48、USB-C、SWD、晶振/LDO/ESD、二极管与被动元件。13+8 LED 独立命名与分组，铜触点/孔环/焊盘与少量丝印。渲染拆去壳的上下表面和夜间低亮整机；光源与 LED 对应，不能以无来源的浮光代替灯。
6. **材质精修和交互**：白色微层纹打印壳、黑阻焊 PCB、金色铜、银色金属、透明塑料、棕色轴芯、黄色键帽。适量倒角/法线，无装饰性过度划痕。建立 Blender 侧栏 UI，每键按钮/压下量、旋钮角/按压、摇杆 X/Y/按压、LED 亮度颜色、explode 0..1、全部复位。使用驱动器/约束与独立控制 Empty，运动限值列明来源或近似。
7. **动画/交付与总验收**：提供 assembled / exploded / interaction demo 动作或时间段；同一个滑块可从装配态恢复到解构态，保持连接件归属。最终渲染日/夜三分之四、顶/前/侧/后、内部上/下、爆炸图与控制极限；实际查看每张并记录缺陷与修正。保存可重开 .blend、交互脚本和操作说明。

## 验收判据

可通过官方MCP执行`tools/read_only_scene_audit.py`，输出`references/live_scene_audit.json`。脚本只记录当前几何/控制证据：13帽/控制器、相对KiCad的XY误差、无效驱动器、USB评估世界包围盒、LED命名识别及壳板/摇杆参考体。它不修改场景控制值，也不代替运动碰撞检查、视觉审看或最终重开验收；不得因计数通过就设置complete=true。09:41初次执行仍发现USB组远离板框，LED尚未创建。

- 数量：13 套按键；1 旋钮；1 摇杆；1 触摸片；13 键灯+8 周边灯；四角紧固。
- 尺寸：板壳尺寸和 XY 位置由 CAD/PCB 证据核对；所有近似高度单列；禁止截图猜尺寸。
- 机械：孔同轴、PCB 在承托面、USB 开口对口；键帽连接轴芯；运动极限不穿帮；爆炸0恢复每个原位矩阵。
- 外观：参考实拍布局、真实黑 PCB 露出、白打印壳；材质与灯光不过曝；13 键可数且图标清晰。
- 交互：实际遍历13键；旋钮旋转/按压；摇杆X/Y/按压；重置和爆炸恢复；记录可见结果和驱动器有效性，不能只检查属性存在。
- 每批必须落地 png 渲染并实际打开审看，日志写明看过哪些图、发现问题、修正后证据。Python 返回成功不等于视觉验收通过。
- 最终重开保存的 .blend，检查资源缺失、交互脚本加载方式、对象层级、动作和渲染。交付完整操作说明。

## 断点协议

每个小步骤保存 `assets/OpenMicroKbd.blend` 和批次 checkpoint；更新 `progress.json`、`工作日志.md`。进度包含 completed_batches、next_action、known_issues、render_paths、visual_reviews、complete、audit_complete。不允许仅在最终回复中记录进度。

当额度剩余≤6%时优先收尾保存；观察到剩余≤5%立即停止继续推理/发新制作指令。额度查询失败时停止新批次并保存，不能盲目继续。不使用额度重置券。8:40任务读取真实断点；已有执行器活动则排队而非第二个实例同时改 Blender。若已完成，第二任务重开文件再做一次完整验收。
