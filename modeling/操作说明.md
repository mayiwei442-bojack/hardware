# OpenMicroKbd V1 模型操作说明

## 打开与操作

用 Blender 5.2 打开 `assets/OpenMicroKbd.blend`。当前电脑已安装并启用 **OpenMicroKbd Controls** 插件，在 3D 视图按 **N → OpenMicroKbd** 即可操作。

换电脑时，在插件设置中“从磁盘安装”并启用 `tools/openmicro_controls.py`。也可在 Scripting 工作区选择模型内置文本 `OpenMicroKbd_Controls.py`，点击“运行脚本”；这种方式每次重启 Blender 后需要重新运行。没有开启全局脚本自动执行。

| 控制 | 用法 |
|---|---|
| 13 个按键 | 点击中文按钮切换按下/松开；行程0–1可连续调整，每键独立 |
| 旋钮 | 旋转角度（度）与按下量（0–1） |
| 摇杆 | X、Y倾角与按下量；绑定限制合成倾角 |
| 灯光 | 亮度0关闭、1最亮；颜色控制全部21颗RGB LED |
| 触摸反馈 | 0–1控制触摸铜片的演示高亮 |
| 解构 | 0装配，1完整分层；可连续拖动 |
| 全部复位 | 停止示范，恢复装配、中立姿态与默认蓝光；保留动画数据 |
| 记录姿态 | 给当前帧的22项控制插入关键帧，继续制作自己的动画 |
| 播放 / 停止示范 | 播放1–360帧、30fps的12秒演示；再次点击停止并回到手动控制 |

默认使用实体视图，方便流畅操作。查看真实透明材质、金属反射和灯光，按 **Z → 渲染**；按 **F12** 渲染当前相机。Cycles配置为本机RTX 4060 Laptop GPU / OptiX；换电脑时可改用自己的GPU或CPU。

## 动画与层级

预制NLA轨道名为 `OpenMicroKbd Demo`，默认静音，避免覆盖手动滑块。时间轴依次展示按键、旋钮、摇杆、触摸/RGB、解构、重装配。播放时用 `CAM_Demo`，手动状态用 `CAM_Hero`。

“记录姿态”会创建自己的活动Action。它与预制NLA同时启用时，Blender按常规规则混合动画；专门观看预制示范前，可先在动画编辑器解除自己的活动Action。不要删除 `DEMO_…` 动作。

全部可见模型部件归属 `OMK_ROOT_CTRL`。解构滑块到1时，相对装配状态的Z位移为：

| 层级 | 位移 |
|---|---:|
| 外壳 | 0 mm |
| 底面电子件 | 18 mm |
| PCB、板面小件、周边LED、触摸片 | 38 mm |
| 开关与旋钮/摇杆机械机构 | 65 mm |
| 键帽、旋钮帽、摇杆帽 | 95 mm |
| 四角紧固件 | 115 mm |

各键 `SW##_Assembly`、`SW##_KeyMotion`、`SW##_CapDetach` 保持独立。帽、轴芯、外壳、针脚分别命名；电子部件按PCB位号分组，LED封装、透镜、光源各自独立。原CAD留在隐藏的 `99_SourceReferences` 集合。

## 尺寸与精度边界

- PCB 95×95×1.6 mm，外壳99.4×99.4×12.6 mm；场景1数值单位代表1 mm，单位比例0.001。
- 外壳、旋钮帽、摇杆帽使用提供的V1 CAD，部件XY布局来自KiCad，全部88个位号有对应。
- Choc采用Kailh CPG1353家族图参考，按键全行程3.2 mm。BOM中WL-LP-SW-55G无独立机械图；17.2 mm键帽宽度、曲面及内部简化结构为照片拟合和可视化近似。
- EC11按压0.50 mm是视觉代理，未将其他后缀型号的行程冒充本型号实测值。
- RKJXV合成倾角限制约23°、按压0.40 mm；双轴同时输入23°时会归一化。
- MCU、LDO、ESD、晶振、插座、二极管、电阻电容按封装族作可识别简化，没有铜走线、芯片内部结构或电气仿真。
- 触摸铜片直径9 mm；触摸高亮与RGB控制是动画效果，不连接真实键盘硬件。

## 文件

- `assets/OpenMicroKbd.blend`：模型、驱动、材质、相机、预制动画与内置控制脚本。
- `renders/final_hero.png`、`final_night.png`、`final_exploded.png`：整机、夜间灯光、分层渲染。
- `renders/final_top.png`、`final_front.png`、`final_right.png`、`final_rear.png`、`final_usb.png`：装配视图。
- `renders/final_pcb_top.png`、`final_pcb_bottom.png`：PCB正反面。
- `renders/final_demo_*.png`：实际示范动画的关键帧。
- `验收报告.md`、`references/*audit.json`：检查范围与证据。
- `checkpoints/`：历史断点；`tools/`中的生成脚本是过程记录，不要对正式文件重复运行整套建模脚本。
